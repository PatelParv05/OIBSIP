# Task 3 - SQL Injection on DVWA

## Objective

Demonstrate a basic SQL Injection vulnerability using DVWA
(Damn Vulnerable Web Application) running locally with its
security level set to Low.

## Tools Used

- DVWA
- Kali Linux / Linux local environment
- Apache
- MySQL/MariaDB
- Web Browser
- Burp Suite (optional)

## Scope

All testing will be performed only against a locally hosted
DVWA instance for educational and authorized security testing.
